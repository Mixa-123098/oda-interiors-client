# oda-interiors-client

React frontend for [oda-interiors.com](https://oda-interiors.com) — a production
website for an interior design and architecture studio.

Built and maintained solo since 2023.
Backend: [oda-interiors-server](https://github.com/Mixa-123098/oda-interiors-server)

## Features

- Public site: project portfolio, services, contact
- Admin interface — the studio manages portfolio entries and page content
  themselves, without developer involvement
- Multilingual content served from the backend
- Responsive layout (Bootstrap)

## Stack

React · Bootstrap · REST API

## Running locally

```bash
npm install
npm start
```

Requires the backend running locally.
